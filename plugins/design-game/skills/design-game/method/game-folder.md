# Папка игры

Создаёт `scripts/init_game.py`; повторный запуск досоздаёт недостающее и существующее не трогает.

```
<папка игры>/                     в проекте обычно <проект>/design/, сборка — рядом, в <проект>/build/
  BIBLE.md                        Библия проекта: собирает scripts/build_bible.py, руками не правится
  00-heart/CONTROLLING-IDEA.md    стержень и паспорт игры
  00-heart/AUDIENCE.md            анкета аудитории — гейт аудитории в конце стадии 0
  00-heart/HEART.md               стадия 0
  00-heart/research/              наблюдения и записи; probes/ — зонд до фиксации идеи
  01-concept/CONCEPT.md           стадия 1 (variants/ — независимые прогоны концепта, если включены на брифе)
  02-mechanics/MECHANICS.md       стадия 2, probes/ — зонды
  03-balance/BALANCE.md           стадия 3, sims/ — симуляции, probes/
  04-experience/EXPERIENCE.md     стадия 4
  05-narrative/NARRATIVE.md       стадия 5 или статус SKIP с причиной
  06-playtest/PLAYTEST.md         стадия 6, probes/, sessions/ — протоколы, согласия, отчёты агента-игрока
  07-release/RELEASE.md           стадия 7, PITCH.md, BUILD-HANDOFF.md
  logs/RISKS.md                   реестр рисков
  logs/LENS-LOG.md                журнал линз
  logs/CONSISTENCY.md             сверки хранителя
  logs/DECISIONS.md               журнал решений
  logs/errors.json                грабли проекта
```

Правила:

- В корне папки игры — только `BIBLE.md`, всё остальное — в папках стадий и `logs/`.
- Один файл стадии — один писатель. Журнал решений и Библию ведёт оркестратор. Реестр рисков лежит в папке игры с начала, на стадии 1 его наполняет `gd-concept`, дальше ведёт оркестратор; стадийные роли предлагают строки в отчёте.
- Зонд лежит в `probes/` стадии, где поднят риск: `NN-*/probes/probe-<номер>-<slug>/` с `PROTOTYPE-PROBE.md` и `probe.json`. Номер сквозной по всей игре: следующий за самым большим из существующих.
- Библия — единственный документ, который можно отдать человеку со стороны «прочитать всё». Правки вносятся в файлы стадий, потом Библия пересобирается.
- Документы, не относящиеся к дизайну (контракты платформы, схемы данных, код), лежат рядом с папкой игры, не внутри.
