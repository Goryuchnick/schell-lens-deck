# История версий

## 4.0.0

- Колода пересобрана по книге: 113 линз своими словами, номер и название из русского издания у каждой, английские названия сверены с третьим изданием; добавлена 93½ «Присутствие»; придуманные линзы убраны; наши линзы помечены «не Шелл».
- Скилл — самодостаточная папка плагина Claude Code; установщик `install.py` для Codex и Claude Code без плагина.
- Скрипты вместо догадок модели: подбор линз по паспорту игры, проверка стадии, входящие владельца, карточка гейта, окупаемость.
- Правило цикла и возвраты, реестр рисков, восемь фильтров на каждом гейте, единый вердикт хранителя.
- Гейт аудитории, агент-игрок, интервью под каждую аудиторию, согласие на запись плейтеста.
- Слои по паспорту: заказчик, рекламные и обучающие игры, безопасность детей в общении.
- Вход «продолжим игру», перенос вопросов через гейт, дизайн поверх уже собранной игры.
