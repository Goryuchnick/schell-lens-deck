## Уроки

### #001 — Advergame: линзы Шелла play-centric, число-наружу = отдельная ответственность

**Статус:** внедрён  
**Промоучено в:** `gd-balance` (запрос источника перед числом-наружу), `gd-keeper` (DRIFT по Honest Claim / Responsibility), линза **Honest Claim** добавлена в `lenses.md`, **advergame-overlay** (§2.5-bis SPEC) вынесен как явный слой.

**Урок:**  
Линзы Шелла проектировались для entertainment: они оценивают ценность **внутри** игры (endogenous value — fun, challenge, flow). Для рекламных и обучающих игр появляется второй слой: ценность, которую игра **выносит наружу** как реальное обещание (числа, результаты, экономия).

Эти два слоя разделены:
- Endogenous value — покрывается стандартными линзами (Challenge, Reward, Economy).
- External claim — уходит под **Honest Claim + Responsibility**: любое число или обещание наружу обязано быть правдивым и защитимым, иначе подрывает доверие.

**Следствия для скилла:**
- `gd-balance` не выдаёт числа-наружу молча — запрашивает источник или явно помечает «иллюстративно».
- `gd-keeper` ловит непомеченные числа как `DRIFT (Responsibility / Honest Claim)`.
- Линзы Secret Purpose + Honest Claim + Responsibility вытягиваются из стадии 7 вперёд при типе `advergame / serious`.
- Тип игры и truth-ограничения фиксируются в `CONTROLLING-IDEA.md` уже в стадии 0.
