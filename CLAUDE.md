# CLAUDE.md — schell-lens-deck

Публичный репозиторий скилла `design-game`: пайплайн гейм-дизайна по линзам Джесси Шелла. Для Claude Code это маркетплейс с одним плагином, для Codex — `install.py`. Пользователи ставят его по ссылке на GitHub, поэтому всё в репозитории — для чужих глаз.

## Раскладка

- `plugins/design-game/skills/design-game/` — сам скилл, самодостаточная папка: `SKILL.md`, `WIKI.md`, `lenses/`, `stages/`, `method/`, `templates/`, `scripts/`. Все пути внутри — от этой папки.
- `plugins/design-game/agents/gd-*.md` — роли. `install.py` переводит их в TOML для Codex.
- `.claude-plugin/marketplace.json`, `plugins/design-game/.claude-plugin/plugin.json` — манифесты.
- `docs/SPEC.md` — спецификация, `docs/LESSONS.md` — уроки, `CHANGELOG.md` — версии.

## Источники истины

- `lenses/lenses.json` — что такое линза; `stages/stages.json` — когда её брать. Скрипты читают только их, поэтому списки линз в текстах не дублируются.
- Формат вердикта хранителя (`## Сверка после стадии NN` и строка `**Вердикт:**`) машинно читают `build_bible.py` и `gate.py`: меняешь формат — меняешь и скрипты.
- Заголовки `##` шаблонов стадий — обязательные разделы для `check_stage.py`; пометки `<!-- по тегу: … -->`, `<!-- по полю: … -->`, `<!-- необязательно -->` — его же язык.
- Паспорт игры в `templates/CONTROLLING-IDEA.md` разбирает `pick_lenses.py`: ключи и формат блока не менять без правки скрипта.

## Правила

- Текст линз и метода — своими словами: без цитат и без примеров из книги. Перед выпуском сопровождающий сверяет изменённые тексты с книгой по 8 слов подряд; совпадение переписывается. Причина — правообладатель запрещает копировать текст книги.
- Примеры — выдуманные. Ни имён людей, ни проектов, ни путей чьей-то машины.
- Скрипты — только стандартная библиотека Python 3.9+, без f-строк с обратной косой чертой в выражениях.
- Модели ролей — только алиасы `opus`, `sonnet`, `haiku`; `effort` в скилле не задаётся.
- Наши линзы и правила, которых нет у Шелла, помечаются «наша, не Шелл».

## Проверка изменения

- `claude plugin validate .` и `claude plugin validate plugins/design-game` — без ошибок.
- На временной папке: `init_game.py` → заполнить паспорт → `pick_lenses.py` → `check_stage.py` (с `--before-keeper` и без) → `gate.py` → `build_bible.py`.
- `python install.py --codex --project <временная папка>` и `--claude --project <другая>`: TOML ролей читается `tomllib`.
- Запись в `CHANGELOG.md`; урок системы — строкой в `docs/LESSONS.md`.
